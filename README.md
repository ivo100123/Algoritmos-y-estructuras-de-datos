# Algoritmos-y-estructuras-de-datos

1- Nivel "Básicos"1.1 Suma y Promedio:
Crea un programa que inicialice un arreglo con 10 números enteros. Calcula y muestra en consola la suma de todos los elementos y su promedio.
Concepto clave: Recorrido de arreglos con bucles (for o foreach).
1.2 Buscar el Mayor y el Menor:
Dado un arreglo de 8 números enteros desordenados, implementa un algoritmo que encuentre cuál es el número mayor y cuál es el menor, imprimiendo ambos valores y sus respectivas posiciones (índices).
Concepto clave: Condicionales dentro de un bucle y actualización de variables de control.
2- Nivel "Intermedios"2.1-Invertir un Arreglo:
Escribe un método que reciba un arreglo de cadenas de texto (por ejemplo, nombres) y lo invierta modificando el arreglo original sin crear uno nuevo para el resultado.
Concepto clave: Intercambio de variables (swapping) y uso de dos índices simultáneos (inicio y fin).
2.2-Filtrar y Copiar (Números Primos):
Crea un arreglo original con 15 números aleatorios entre 1 y 50. Luego, identifica cuántos de ellos son números primos y transpórtalos a un nuevo arreglo que tenga el tamaño exacto para contenerlos (sin dejar espacios vacíos ni ceros al final).
Concepto clave: Arreglos dinámicos simulados, funciones de verificación y dimensionamiento preciso.
2.3-Frecuencia de Elementos:
Escribe un programa que reciba un arreglo de 10 caracteres e imprima en consola cuántas veces se repite cada carácter. (Por ejemplo: si el arreglo tiene ['a', 'b', 'a', 'c'], debe indicar que 'a' aparece 2 veces, 'b' 1 vez, etc.).
Concepto clave: Control de elementos ya visitados o uso de arreglos auxiliares de conteo.
3- Nivel "Avanzados"3.1-Rotación de Elementos:
Desarrolla una función que reciba un arreglo de enteros y un número de posiciones a rotar. El programa debe desplazar los elementos del arreglo hacia la derecha esa cantidad de veces. Por ejemplo, si el arreglo es [1, 2, 3, 4, 5] y se rota 2 posiciones, el resultado debe ser [4, 5, 1, 2, 3]. Optimiza el código para que funcione eficientemente incluso si el número de rotaciones es mayor que la longitud del arreglo.
Concepto clave: Operador residuo (%) y algoritmos de rotación eficiente.
3.2-Eliminación de Duplicados en un Arreglo Ordenado:
Dado un arreglo de enteros que ya se encuentra ordenado de menor a mayor de forma ascendente, escribe un algoritmo que elimine todos los elementos duplicados directamente en ese arreglo, de modo que cada elemento aparezca solo una vez. Los elementos válidos deben quedar al principio del arreglo y la función debe retornar la nueva longitud lógica del arreglo.
Concepto clave: Técnica de dos punteros (lectura y escritura) sobre estructuras contiguas.
